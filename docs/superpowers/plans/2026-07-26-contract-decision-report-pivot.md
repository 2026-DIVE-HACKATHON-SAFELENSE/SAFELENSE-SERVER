# Contract Decision Report Pivot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 여러 후보 매물의 수집 근거를 분석하고 계약 안전성, 거주 영향, AI 해석, 행동 가이드를 포함한 재분석 가능한 계약 전 리포트를 제공한다.

**Architecture:** 기존 계약 단계별 분석 케이스와 결과는 과거 호환용으로 유지한다. 새 `AnalysisRun`이 비동기 실행의 소유자이며 수집 사실과 문서 추출 결과를 불변 근거로 저장한다. 규칙 엔진은 정규화된 사실을 평가하고, OpenAI는 존재가 검증된 근거 ID만 인용하는 JSON 리포트를 생성한다.

**Tech Stack:** Kotlin 2.3, Spring Boot 4.1, Spring MVC, Spring Data JPA, PostgreSQL/Flyway, AWS SDK S3/KMS, OpenAI API, OpenPDF, JUnit 5/Testcontainers.

## Global Constraints

- 첫 출시는 내부 데모이며 모든 수집 결과와 리포트에 `dataMode=DEMO`를 표시한다.
- 사용자는 여러 후보 매물을 가질 수 있으며 보증금은 0보다 큰 만원 단위 정수다.
- 위험 사실은 공개 API에서 받지 않고 서버 수집·OCR 결과만 분석 입력으로 사용한다.
- 등기부 원본은 SSE-KMS 비공개 S3에 최대 30일 보관하고 DB에는 파일 바이트를 저장하지 않는다.
- AI 요청에는 주소 원문, 임대인 이름, 문서 원본을 보내지 않는다.
- 누락·오류·오래된 데이터는 안전 판정으로 변환하지 않는다.
